# Changelog

## 1.0.0 - 2026-08-04

- Phát hành HomeWork desktop cho Windows x64.
- Bổ sung tổng quan, công việc, dự án, hoạt động và cài đặt.
- Lưu workspace ngoại tuyến tại `%APPDATA%\HomeWork`.
- Thêm giao diện sáng/tối và nhận diện thương hiệu mới.
- Tự động tạo `HomeWork-Setup.exe` và portable ZIP qua GitHub Actions.
